# A Little Universe for You

Website ucapan ulang tahun interaktif dengan tema midnight blue minimalis.

## Menjalankan project
1. Buka folder ini di VS Code.
2. Letakkan foto di `assets/images/gallery/birthday-photo.jpg`.
3. Jalankan `index.html` menggunakan Live Server.

Karena JavaScript menggunakan ES Modules, jalankan melalui Live Server atau server lokal, bukan membuka file HTML langsung.

## Struktur
- `index.html`: struktur halaman.
- `assets/css/`: styling, animasi, dan responsive.
- `assets/js/`: navigasi, wishes, surat, birthday, dan efek.
- `assets/images/`: foto dan aset visual.
- `assets/audio/`: tempat menyimpan musik pilihan.

## Kustomisasi
Ubah teks ucapan langsung di `index.html`. Ganti foto dengan file bernama `birthday-photo.jpg` di folder galeri.
